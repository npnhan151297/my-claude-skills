# Logo dùng cho bộ slide Google for Education

Nguồn: gói "Quy chuẩn thiết kế slide AIE" (người dùng cung cấp). Icon Workspace là bản 2026q2, 192×192 px (2x, 96dp).
Giữ nguyên màu và tỉ lệ, không đổi màu, chừa khoảng trống quanh logo.

- Icon sản phẩm: `gmail`, `calendar`, `drive`, `docs`, `sheets`, `slides`, `forms`, `meet`, `chat`, `keep`, `sites`, `admin`, `voice`, `editors`, `classroom` (.png; `classroom.svg` là bản gốc), `gemini`, `gemini-notebook`.
